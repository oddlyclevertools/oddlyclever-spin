Get the app

Windows

Its own window, a Start menu shortcut and media keys. Installs just for you, no admin needed.

Download for Windows
Android

The same app on your phone. It isn't on Google Play, so you install the file yourself.

Download APK
Scan this with your phone's camera

  1. Your phone needs to be on the same Wi-Fi as this PC.
  2. Open the link. If Chrome warns about the file, tap Download anyway, then Open.
  3. First time only: Android asks to allow installs from this source. Tap Settings, turn on Allow from this source, then go back.
  4. Tap Install. If Play Protect asks, tap More details › Install anyway.
